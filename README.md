# Amazon-Product-analytics Dashboard

## Project Overview
This project analyzes Amazon Product to understand product categories, pricing, discounts, customer ratings and review patterns.

##Tools Used 
-Microsoft Excel
-PostgreSQL(SQL)
-Microsoft Power BI

##Project Objectives 
-Analyze product Distribution across categories
-Compare Average product ratings
-Analyze discount patterns
-Study ratings by review count
-Compare budget, mid-range and premium Products
-Build an interactive Power BI Dashboard

##Project Workflow
1. Data cleaning Using Excel
2. Data analysis Using PostgreSQL
3. Dashboard Creation Using Power BI

##Key Findings 
-Electronics has the Highest number of products .
-Products with more reviews have higher average ratings in the dataset.
-Higher discounts do not necessarily mean higher ratings.
-Premium products have a higher average rating than Budget and mid-range products in the dataset.
